【DDD 规范：Entity 实体】
1. 有唯一 ID，是数据与行为的聚合
2. 业务逻辑写在实体内部（如 user.enable()、order.pay()）
3. 禁止 setter 泛滥；状态变更通过领域方法
4. 关联对象用引用，不直接暴露数据库结构
5. 与表结构映射，但不完全等同
6. 不变量约束在实体内部校验（非空、状态合法、规则判断）

示例：
public void audit() {
if (this.status != DRAFT) throw new BizException("只能审核草稿");
this.status = AUDITED;
this.auditTime = now();
}
