【DDD 规范：Repository】
1. Domain 层定义接口：UserRepository
2. Infra 层写实现：UserRepositoryImpl
3. 实现内部调用 MyBatis-Plus BaseMapper
4. 方法名面向领域：findById、save、remove、findByCondition
5. 禁止返回 List<Entity> 直接给 Controller
6. 分页统一返回 IPage<Entity>
7. 禁止在 Repository 写业务逻辑，只做数据存取

示例：
public interface UserRepository {
Optional<User> findById(Long id);
void save(User user);
IPage<User> page(Query query, Page<User> page);
}
