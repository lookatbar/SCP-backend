【DDD强制红圈规则】
1. 仅使用 MyBatis-Plus 3.4.3 官方真实 API，**禁止编造方法/类/注解**
2. 禁止手写 SQL；复杂查询必须用 LambdaQueryWrapper + XML
4. 统一返回 Result<T>，禁止直接返回 Object/Map/String
5. 必须加 @Transactional(rollbackFor = Exception.class)
6. DTO/VO 必须 @Valid + JSR380 校验；Entity 禁止直接返回
7. 分页必须用 Page/IPage；禁止手动 limit/offset
8. 命名严格遵循驼峰；表/字段映射必须 @TableName/@TableId/@TableField
9. 禁止空指针：查询结果必须判空；集合用 CollectionUtils/Optional
10. 严格四层架构：Application → Domain → Infrastructure → Interface
11. 核心逻辑只写在 Domain（Entity / Domain Service），禁止写在 Application
12. 禁止贫血模型：Entity 必须携带行为方法
13. Repository 只定义接口在 Domain，实现写在 Infrastructure
14. 禁止 Service 直接调用 Mapper
15. 禁止事务写在 Controller，事务统一在 Application 层
16. 入参：Cmd / Query；出参：VO；禁止 Entity 直接对外
17. 领域事件按需使用，禁止滥用
18. 所有业务规则必须显性表达，不隐藏在 SQL 或 MP 中
10. 不遵守以上规则则重新生成
