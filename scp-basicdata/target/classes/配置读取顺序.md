### springboot alibaba 读取配置顺序：
1️⃣ Nacos 配置中心 配置（优先级最高）
 - 项目启动最先加载，会覆盖本地所有配置
 - bootstrap.yml 连接 Nacos
 - 拉取：${服务名}.yaml

2️⃣ 命令行参数
 - 启动时 --key=value

3️⃣ Java 系统属性
 - System.getProperties()

4️⃣ 操作系统环境变量

5️⃣ bootstrap.yml / bootstrap.properties
 - 只用来连接 Nacos，优先级高于 application

6️⃣ application.yml / application.properties
 - 本地普通配置

7️⃣ 默认配置（starter 内部）
 - 优先级最低
